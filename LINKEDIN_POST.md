## 🚀 Option 1: Technical & Industry-Focused (Recommended)
*Best for showcasing deep engineering competence, architecture design, and hands-on FortiGate/Cisco skills to recruiters and senior network/security engineers.*

```markdown
🚀 Excited to share my latest hands-on project: Building an Enterprise FortiGate Next-Generation Firewall (NGFW) Perimeter & Micro-Segmentation Lab!

In modern enterprise infrastructures, perimeter defense and internal network segmentation are vital to stop threat actors and eliminate unauthorized lateral movement. 

I designed and deployed a multi-zone enterprise network from scratch using Fortinet FortiOS and Cisco Layer 3 routing:

🔑 Key Architecture & Technical Highlights:
🔹 Multi-Zone Security Segmentation: Isolated corporate network zones into Corporate Users (VLAN 10), Developers (VLAN 20), Administrators (VLAN 30), and an isolated DMZ (VLAN 99).
🔹 Dynamic Routing with OSPF: Implemented OSPF Area 0 between the Core Cisco L3 switch and FortiGate NGFW with dynamic default route origination and passive-interface security hardening.
🔹 Demilitarized Zone (DMZ) & Web Publishing: Configured Virtual IP (VIP / Destination NAT) on FortiGate to securely publish an internal Cisco web server (pinglabs.in) to the public Internet while strictly enforcing Zero Trust isolation towards internal LAN subnets.
🔹 Dual-Tier NAT Mechanics: Implemented Source NAT (PAT Overload) for internal user Internet egress and edge carrier translation on the ISP router.
🔹 Out-of-Band Management (OOBM): Isolated management plane on a dedicated host-only network (192.168.254.0/24) for secure HTTPS GUI and SSH administration.

I have documented the entire architecture, IP schema, routing tables, security policy matrices, and ready-to-deploy configuration scripts in my GitHub repository:

👉 GitHub Repository: https://github.com/RakeshMehta01/Fortigate-Network-Security-Lab.git

Would love to hear your thoughts and feedback from the network and cybersecurity community!

#Cybersecurity #NetworkSecurity #Fortinet #FortiGate #Firewall #Cisco #RoutingAndSwitching #OSPF #InfoSec #SOC #NetworkEngineering #HandsOnLab #Portfolio
```
